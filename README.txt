## Files

## How to run
1. Extract/open this folder in VS Code.
2. Open `index.html`.
3. Use the Live Server extension in VS Code, or double-click `index.html` to open it in a browser.

## Editable content
All portfolio text is directly inside `index.html`.
Colors, spacing, cards and responsive styling are inside `style.css`.
Navigation, reveal animations and the mobile menu are inside `script.js`.
